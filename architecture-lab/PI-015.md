## 1. Objetivo Geral

Esta Product Interpretation (PI-015) documenta retrospectivamente a arquitetura implementada durante a fase de **Product Evolution & Module Unification**, consolidando as alterações de navegação, experiência do usuário e integração entre módulos realizadas após a PI-014.

A PI-015 materializa a transição da arquitetura modular proposta pela PI-014 para uma experiência de usuário coesa, com fluxos de navegação documentados, deep linking entre módulos e refinamentos visuais consistentes.

Nenhuma Frozen Baseline foi alterada. Todas as implementações permaneceram na Presentation Layer.

---

## 2. Motivação

### 2.1 Estado Anterior (Pós PI-014)

A PI-014 definiu a arquitetura modular com ModuleLayout, ModuleTabs e ModuleBreadcrumb, e estabeleceu os módulos Carteira e Análise como referência. No entanto:

- Não existia documentação oficial dos fluxos de navegação entre módulos.
- A navegação entre módulos frequentemente terminava em "becos sem saída" (dead ends).
- Os módulos funcionavam de forma isolada — não havia continuidade natural entre Carteira, Ativo, Análise e Dividendos.
- O Dashboard era uma página isolada com KPIs sem conexão com outros módulos.
- A experiência visual dos módulos (tabs, header, breadcrumb) ainda apresentava pequenas inconsistências.

### 2.2 Oportunidades Identificadas

| Oportunidade | Impacto |
|-------------|---------|
| Ausência de mapeamento oficial de navegação | Dificuldade de planejamento de novas integrações |
| Dead ends entre módulos | Usuário precisa usar o menu para cada transição |
| Dashboard não funcionava como Hub | Perda de oportunidade de ser o ponto central |
| Inconsistências visuais entre módulos | Experiência fragmentada |

---

## 3. Escopo

### 3.1 Incluído

- Mapeamento oficial dos fluxos de navegação da plataforma (USER_FLOWS.md).
- 5 princípios de navegação (P-NAV-001 a P-NAV-005).
- Deep linking entre módulos: Comparador→Carteira, Dividendos→Empresa, Ativo→Análise, Carteira→Provisionador.
- Links contextuais em todas as listas de ativos da Carteira e Proventos.
- Refinamento visual dos componentes modulares: ModuleTabs, ModuleHeader, ModuleBreadcrumb.
- Estados ativos mais visíveis no SiteHeader e navegação mobile.
- Transformação do Dashboard em Hub Central com Quick Actions, ContextPanel, RecentActivity, SmartHints, RelatedLinks.

### 3.2 Excluído

- Alteração de Frozen Baselines.
- Modificação de regras de negócio.
- Criação de novas funcionalidades (apenas conexão entre existentes).
- Criação de novas páginas.
- Alteração de autenticação.

## 4. Diretrizes Arquiteturais

### 4.1 Princípios de Navegação (P-NAV)

Os fluxos de navegação obedecem a 5 princípios:

| Princípio | Descrição |
|-----------|-----------|
| **P-NAV-001** — Navegação não redundante | Cada funcionalidade tem exatamente um caminho principal de acesso. |
| **P-NAV-002** — Redução de cliques | Máximo de 3 cliques da Home para qualquer funcionalidade. |
| **P-NAV-003** — Preservação de contexto | Ao navegar entre módulos, o contexto do usuário é preservado. |
| **P-NAV-004** — Reutilização de componentes | Usar ModuleLayout, ModuleTabs, ModuleBreadcrumb, ModuleSection, SiteHeader, MobileNav. |
| **P-NAV-005** — Identidade de cada módulo | Cada módulo mantém identidade própria via ModuleLayout. |

### 4.2 Deep Linking

A navegação contextual entre módulos segue o padrão de **Link do TanStack Router**, sem criar novas rotas ou redirecionamentos intermediários. Cada integração aponta diretamente para a rota de destino.

| Integração | Rota de origem | Rota de destino | Tipo |
|-----------|---------------|-----------------|------|
| Comparador → Carteira | `/comparar` | `/carteira` | Botão "Minha Carteira" |
| Comparador → Ativo | `/comparar` | `/ativo/$ticker` | Ticker clicável |
| Dividendos → Ativo | `/dividendos` | `/ativo/$ticker` | Ticker + nome da empresa clicáveis |
| Ativo → Análise | `/ativo/$ticker` | `/analise` | Botão "Análise" no header |
| Carteira → Provisionador | `/carteira/proventos` | `/provisionador` | Botão "Provisionador completo" |
| Dashboard → Módulos | `/dashboard` | `/carteira`, `/analise`, etc. | Quick Actions grid |

### 4.3 Dashboard como Hub Central

O Dashboard (`/dashboard`) foi transformado na primeira tela pós-login, funcionando como Hub Central com:

| Bloco | Função | Componentes utilizados |
|-------|--------|----------------------|
| Quick Actions | Atalhos para módulos principais | Links + ícones |
| Sua Carteira | KPIs, insights, charts | DashboardView (existente) |
| Context Panel | Status da carteira, proventos, valores | ContextPanel |
| Recent Activity | Timeline de operações recentes | RecentActivity |
| Smart Hints | Recomendações contextuais | SmartHints |
| Related Links | Navegação para módulos relacionados | RelatedLinks |

### 6.2 Componentes Modulares

| Componente | Arquivo | Responsabilidade |
|-----------|---------|-----------------|
| `ModuleLayout` | `module-layout.tsx` | Layout padrão: breadcrumb + header + tabs + conteúdo |
| `ModuleHeader` | `module-header.tsx` | Cabeçalho com título `text-2xl font-bold` e descrição |
| `ModuleBreadcrumb` | `module-breadcrumb.tsx` | Navegação contextual: Home > Módulo > Sub-página |
| `ModuleTabs` | `module-tabs.tsx` | Abas de navegação interna com CSS truncation |
| `ModuleSection` | `module-section.tsx` | Seção de conteúdo com título e ação |

### 6.3 Estados Ativos

Os estados ativos de navegação seguem o padrão:

| Elemento | Classe CSS | Comportamento |
|----------|-----------|---------------|
| SiteHeader (desktop) | `[&.active]:bg-secondary/60 [&.active]:font-semibold` | Fundo semi-transparente + semibold |
| MobileNavLink | `[&.active]:bg-secondary/60 [&.active]:font-semibold` | Mesmo padrão do desktop |
| ModuleTabs | `isActive ? "bg-background text-foreground shadow-sm"` | Fundo branco + sombra |
