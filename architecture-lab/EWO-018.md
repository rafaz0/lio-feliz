Implementar o Bloco C da PI-013 — Intelligence Layer — estabelecendo a infraestrutura de insights e indicadores objetivos da plataforma, reutilizando exclusivamente dados existentes.

## Escopo

### Inclui

- Infraestrutura base da Intelligence Layer (InsightCard, InsightSection, tipos)
- Indicadores objetivos de patrimônio, diversificação, proventos, metas e rebalanceamento
- Hook unificado useAllInsights para consumo por múltiplas telas
- Integração dos insights no Dashboard

### Não contempla

- Modificação de Core Domain
- Modificação de Application Layer
- Modificação de Infrastructure Layer
- Criação de novas funcionalidades
- Cálculos financeiros novos
- Recomendações de investimento
- Regras de negócio
