## Objetivo

Substituir o módulo de cálculo de carteira legado (`src/lib/portfolio/`) pelo novo domínio (`src/core/domain/portfolio/`) na camada de experiência (frontend), preservando:

- Resultados numéricos (posições, preço médio, patrimônio, rentabilidade)
- Estrutura de dados que os 11 arquivos de frontend consomem
- Zero regressão em cálculos financeiros
- Zero regressão em IRPF (confirmado via rastreio independente)

---

## Decisões Arquiteturais

### DA-001: Separação entre custo fiscal e custo líquido

**Decisão:** O `PortfolioProjector` deve expor dois conceitos distintos:

| Campo | Origem | Uso |
|---|---|---|
| `totalCost` (fiscal) | Soma de compras + fees - vendas | Cálculo de preço médio para IRPF, exportação fiscal |
| `netInvested` (líquido) | `totalCost` - dividendos/JCP recebidos | Métrica de "capital líquido investido" exibida na UI |

**Fonte:** `docs/06_BUSINESS_RULES/08_IMPOSTOS.md` linha 134: custo de aquisição deve incluir apenas preço pago + custos operacionais. Dividendos e JCP não reduzem custo de aquisição para fins de IRPF.

**Impacto:** O `Position` (legado) tem um único campo `invested` que já é o valor líquido (reduzido por proventos). O novo `Position` (domínio) tem apenas `totalCost` (custo puro). O Application Service deve expor ambos.

### DA-002: Preços de mercado na Application Layer

**Decisão:** O `PortfolioProjector` projeta apenas posições (qty, avgCost, totalCost). O cálculo de `currentValue`, `pnl`, `weight` e alocações deve ser feito na Application Layer, combinando as posições projetadas com preços atuais (via server functions existentes).

**Motivo:** O domínio não deve depender de fontes de preço externas. A Application Layer orquestra domínio + dados externos.

### DA-003: History Calculator novo

**Decisão:** Criar um novo `PortfolioHistoryService` na Application Layer que:

1. Projeta posições para cada ponto no tempo (reutilizando `PortfolioProjector`)
2. Interpola em grade temporal semanal (compatível com a atual `buildPortfolioHistory`)
3. Combina com preços históricos (via mock-data ou fonte real)

**Motivo:** O `PortfolioHistoryCalculator` existente no domínio gera snapshots por evento, sem preços de mercado — estrutura incompatível com a que o frontend consome.

## Slices de Implementação

### Slice 1 — Application Service de Posições

**Objetivo:** Criar `ConsultarPosicaoService` que expõe `PortfolioSummary` (compatível com o tipo legado) usando o novo domínio internamente.

**Arquivos novos:**
- `src/application/services/consultar-posicao-service.ts` — implementação concreta

**O que faz:**
1. Recebe `Operation[]` das server functions
2. Converte para `FinancialEvent[]` via mapper (incluindo fees no totalCost)
3. Chama `PortfolioProjector.project(events)` para obter posições
4. Combina posições com preços atuais (recebidos como parâmetro) para computar `currentValue`, `pnl`, `weight`
5. Computa alocações por tipo e setor
6. Retorna `PortfolioSummary` (estrutura idêntica à legada)

**Testes:** Teste de integração que compara saída do service com saída do `consolidatePortfolio` legado para os mesmos dados (usando o teste de equivalência já existente como base).

**Dependências:** Nenhuma (só depende do domínio já implementado)

---

### Slice 2 — History Service

**Objetivo:** Criar `ObterHistoricoPatrimonialService` que gera pontos semanais com preços de mercado, substituindo `buildPortfolioHistory`.

**Arquivos novos:**
- `src/application/services/obter-historico-patrimonial-service.ts` — implementação concreta

**O que faz:**
1. Recebe `Operation[]` das server functions
2. Converte para `FinancialEvent[]` via mapper
3. Para cada semana (desde a primeira operação até hoje):
   a. Projeta posições com eventos até aquela data
   b. Obtém preço histórico do ativo naquela data (via mock-data ou fonte)
   c. Computa `value` (preço × quantidade) e `invested` (custo líquido)
4. Retorna `PortfolioHistoryPoint[]` (estrutura idêntica à legada)

**Testes:** Compara saída do service com `buildPortfolioHistory` legado para os mesmos dados.

**Dependências:** Slice 1 (mapper de eventos)
