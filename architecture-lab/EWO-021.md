## Objetivo

Implementar a infraestrutura reutilizável de módulos da PI-014, criando componentes genéricos de navegação e layout que servirão de base para todos os módulos funcionais da plataforma.

Nenhum Core Domain, Application ou Infrastructure é alterado.

---

## Escopo

### Inclui

- ModuleLayout — layout padronizado de página-módulo
- ModuleHeader — cabeçalho com título, descrição e ação
- ModuleBreadcrumb — navegação contextual
- ModuleTabs — navegação interna por abas (Link-based)
- ModuleSection — seção de conteúdo com título opcional

### Não contempla

- Conteúdo específico da Carteira
- Conteúdo específico de qualquer módulo
- Alteração de Frozen Baselines
- Modificação de Core/Domain/Application/Infrastructure

---

## Reuso de Componentes Existentes

| Componente Novo    | Baseado em                                                                 |
| ------------------ | -------------------------------------------------------------------------- |
| `ModuleBreadcrumb` | Composição sobre `lucide-react` ChevronRight + Home + TanStack Router Link |
| `ModuleTabs`       | Inspirado no padrão shadcn Tabs + TanStack Router `useLocation`            |
| `ModuleLayout`     | Composição de ModuleBreadcrumb + ModuleHeader + ModuleTabs                 |
| `ModuleSection`    | Padrão próprio com props configuráveis                                     |

---

## Resultado

```
ModuleLayout                      →  Layout base do módulo
 ├── ModuleBreadcrumb             →  Navegação contextual (ex: Início > Carteira)
 ├── ModuleHeader                 →  Título + descrição + ação
 ├── ModuleTabs                   →  Navegação interna entre sub-páginas
 └── Conteúdo                     →  Slot para o conteúdo específico do módulo

ModuleSection                    →  Seção reutilizável dentro do conteúdo
 ├── Título (opcional)
 ├── Descrição (opcional)
 ├── Ação (opcional)
 └── Children (conteúdo)
```
